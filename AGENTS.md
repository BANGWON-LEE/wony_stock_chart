# AGENTS.md

## Default Workflow

- Do not require `Superpowers` skills as a default workflow.
- Prioritize `Oh My Codex` style execution: pragmatic decisions, fast iteration, and direct implementation.
- For technical documentation, focus on implementation-ready content with explicit APIs, data models, edge cases, and verification steps.
- Prefer shipping-oriented artifacts over process-heavy templates.

## Documentation Style (Oh My Codex)

- Write docs to reduce immediate implementation risk.
- Include concrete file paths, interfaces, request/response examples, and operational checks.
- Keep documents concise, actionable, and directly mappable to engineering tasks.
- Avoid mandatory process gates unless explicitly requested by the user.

## Instruction Precedence

- User instructions always take precedence over this file.
- If the user asks to use a specific workflow for a task, follow that workflow for the task.
